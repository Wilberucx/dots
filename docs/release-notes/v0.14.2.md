**Fecha:** 2026-06-25

**Tipo:** Features / Bug fixes

## 🚀 Nuevas Funcionalidades

### 1. Diagnóstico preciso para rutas inseguras en `dots doctor`

El comando `dots doctor` ahora ofrece mensajes de error más precisos cuando detecta destinos inseguros (paths fuera de `$HOME`). En lugar de un mensaje genérico, diferencia los casos:

- **`file()` apuntando a `~`:** Sugiere usar un path explícito como `file("source", "~/.archivo")`
- **`dir():to("~")` apuntando a $HOME:** Sugiere usar `dir(...):into("~")` para expandir contenido
- **Paths fuera de `$HOME`:** Mensaje claro indicando el path inseguro

Esto ayuda al usuario a corregir configuraciones que apuntan accidentalmente a `$HOME`.
