# Release Note: v0.14.3 — Bugfixes, docs, and deterministic migration

**Fecha:** 2026-06-25
**Versión:** `v0.14.3`
**Tipo:** Bug fixes / Documentation

## 🐛 Bug Fixes

### 1. `appendLuaFileEntry` inserta correctamente dentro de `files = { ... }`

Corregido un bug donde `dots adopt` agregaba nuevas entradas `file()` al **final del archivo** en lugar de insertarlas dentro del array `files = { ... }` existente. Ahora:

- Si el módulo ya tiene `files = { ... }`, la nueva entrada se inserta antes del `}` de cierre
- Si no existe sección `files`, se crea automáticamente antes del `}` del `return`
- Se respetan strings, escapes y braces anidados (`per_os({...})`, `:when(...)`, etc.)
- La indentación se calcula dinámicamente desde el `}` de cierre

### 2. `IsDotfilesRepo` reconoce `config.lua` como marker

`config.lua` ahora es reconocido como marcador válido de repositorio, además de `init.lua`, `.dots/config.yaml` y `dots.toml`. Esto afecta:

- `IsDotfilesRepo()` — detección de repositorio
- `create()` — inicialización de config para repos Lua
- `loadLuaInitConfig()` — carga de config raíz (fallback a `config.lua` si no existe `init.lua`)

### 3. Migración YAML → Lua determinística con `per-os`

Corregida la iteración no-determinística sobre el mapa `per-os` en `generateFileEntry()`. Ahora las keys se ordenan alfabéticamente antes de iterar, asegurando que la migración `dir():into()` con `per-os` siempre produzca el mismo resultado (`linux` antes que `mac`).
