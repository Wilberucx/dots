# Release Note: v0.12.0 — Embedded Lua Configuration System

**Fecha:** 2026-05-28
**Versión:** `v0.12.0`
**Tipo:** Features / Architecture

## 🚀 Nuevas Funcionalidades

### 1. Configuración con Lua embebido

Se reemplazó el sistema de rutas YAML (`path.yaml`) por un motor Lua embebido (`gopher-lua`), permitiendo configuraciones declarativas mucho más expresivas.

**Dos tipos de archivos Lua:**

| Archivo | Rol | Ubicación |
|---------|-----|-----------|
| `init.lua` | Configuración raíz del repositorio | Raíz del repo |
| `dots.lua` | Configuración de un módulo individual | Dentro de cada módulo |

```lua
-- init.lua
return {
  name = "user/dotfiles",
  module_paths = { "packages/", "configs/" },
  plugins = { "dots.http", "dots.archive", "dots.git" },
}
```

```lua
-- Zsh/dots.lua
return {
  type = "minimal",
  files = {
    file(".zshrc", "~/.zshrc"),
    file(".zshenv", "~/.zshenv"):when("linux"),
  },
  dependencies = {
    pkg "zsh",
    pkg("starship"):on({ pacman = "starship", brew = "starship" }),
  },
}
```

### 2. API de operaciones de archivos

Nuevas funciones globales en Lua para declarar symlinks:

- **`file(source, dest)`** — Archivo individual con métodos `:when(os)`, `:per_os({...})`, `:variant(name)`
- **`dir(source):to(dest)`** — Symlink de directorio completo
- **`dir(source):into(dest)`** — Expandir contenido del directorio
- **`glob(pattern):into(dest)`** — Coincidir por patrón glob

### 3. API de dependencias

Nuevas funciones para declarar dependencias:

- **`pkg(name)`** — Paquete del sistema con `:on({managers})`, `:bin()`, `:post()`, `:fallback()`
- **`curl(url)`** — Descarga binaria con `:extract()`, `:to()`, `:version()`, `:arch({...})`
- **`git(url)`** — Repositorio git con `:to()`, `:at()`, `:post()`

### 4. Sistema de plugins

Tres plugins integrados (embebidos en el binario):

- `dots.http` → `http.download(url, dest)`
- `dots.archive` → `archive.extract_tar()`, `archive.extract_zip()`
- `dots.git` → `git.clone()`, `git.checkout()`

Los plugins personalizados se colocan en `<repo_root>/dots/<name>.lua`.

### 5. `module_paths` en `init.lua`

Controla dónde busca módulos dots, reemplazando la raíz del repo como lugar de búsqueda. Soporta string único o tabla de múltiples rutas.

### 6. `dots edit`

Nuevo comando para abrir la carpeta de un módulo o su archivo de configuración en `$EDITOR`.

### 7. Status con símbolos

`dots status` ahora usa símbolos visuales en vez de solo texto plano.

### 8. Checker con soporte Lua

El syntax checker ahora valida tanto `dots.lua` como `path.yaml`, detectando errores de sintaxis, campos v2, fuentes faltantes y más.

## 🐛 Bugs Corregidos

### 1. Detección de repositorios Lua

`IsDotfilesRepo` ahora reconoce `init.lua` como marker primario, además de los formatos legacy.

### 2. Coexistencia Lua/YAML

Si un directorio contiene tanto `dots.lua` como `path.yaml`, dots.lua toma prioridad con una advertencia.
