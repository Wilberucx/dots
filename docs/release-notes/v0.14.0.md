# Release Note: v0.14.0 — TUI selectors, interactive mode, confirmation prompts

**Fecha:** 2026-06-18
**Versión:** `v0.14.0`
**Tipo:** Features / UI

## 🚀 Nuevas Funcionalidades

### 1. Selector interactivo para `dots link` y `dots unlink`

Cuando se ejecuta `dots link` o `dots unlink` sin argumentos, ahora se muestra un selector TUI (Bubbletea) con lista de módulos. El usuario puede navegar con flechas, seleccionar/deseleccionar con espacio, y confirmar con enter.

```bash
dots link        # → selector interactivo
dots unlink      # → selector interactivo
dots link -i     # mismo comportamiento (flag -i es ahora redundante)
```

Los módulos aparecen preseleccionados por defecto en `link` (para facilitar el flujo rápido), y sin selección en `unlink`.

### 2. Selector de variantes con TUI

El viejo prompt numérico (`1. work  2. personal`) fue reemplazado por un TUI single-select picker que muestra todas las variantes disponibles con indicador visual de la variante activa.

```
Select variant for Zsh:
  ○ personal
  ● work    ← active
```

### 3. Confirmación antes de linkear/deslinkear todos los módulos

Al ejecutar `dots link` o `dots unlink` sin argumentos ni flags, el TUI selector aparece siempre, dando al usuario control explícito sobre qué módulos modificar. Esto previene cambios accidentales.

### 4. Estandarización de selección de módulos

Todos los comandos ahora aceptan nombres de módulo como argumentos posicionales además del flag `-m`:

```bash
dots link Zsh Nvim      # positional args
dots status Zsh Nvim    # igual
dots install Zsh Nvim   # igual
dots unlink Zsh Nvim    # igual
```

Los argumentos posicionales y `-m` se fusionan sin duplicados.

### 5. Selector single-select para `dots edit`

`dots edit` sin argumentos ahora muestra un selector TUI single-select para elegir el módulo a editar, en vez del prompt textual anterior.

## 🐛 Bugs Corregidos

### 1. Prompt de confirmación para link/unlink sin módulos

Antes, `dots link` sin argumentos linkeaba todos los módulos sin preguntar. Ahora siempre muestra el selector interactivo.

### 2. Variant picker en `dots link -m Zsh` sin `--variant`

Cuando se especifica un módulo con variantes pero sin `--variant`, ahora se pregunta interactivamente qué variante usar.
